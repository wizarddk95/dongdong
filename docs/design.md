# 디자인 시스템

색·활자·모서리는 전부 `src/index.css` 의 토큰 한 곳에서 나온다.
컴포넌트는 팔레트 값이나 `#hex` 를 직접 적지 않는다.

## 성격 셋

1. **둥글다.** 모서리는 4~12px. 작은 것일수록 덜, 큰 것일수록 더 둥글다.
   같은 화면에서 반지름이 뒤섞이면 지저분해지므로 역할별로 하나씩만 고른다 —
   칩·인라인 코드 `xs` · 버튼/입력 `sm` · 패널/카드 `md` · 모달/노드 카드 `lg`.
2. **떠 있다.** 층은 면(`canvas` → `surface-1`) 변화 + 아주 옅은 그림자로 낸다.
   진한 그림자는 쓰지 않는다 — `elevate`(카드) 와 `elevate-lg`(모달) 둘뿐이다.
3. **청록 하나.** 크로마틱 액센트는 teal 계열 하나뿐이고 중성색도 거기 맞춰 아주 살짝
   청기를 띤다. **두 번째 브랜드 색을 만들지 않는다** — 뜻이 더 필요하면 라벨·아이콘·
   자리·테두리 굵기로 가른다. 나머지 색은 시맨틱(성공·경고·실패)뿐이다.

## 테마

라이트가 기본, 다크는 설정에서 켠다.
선택값은 `settings.json` 에 저장되고, 첫 페인트 전에 깔리도록 `localStorage` 에도 복사된다
(`index.html` 의 인라인 스크립트가 그 캐시를 읽는다).

```
사용자 선택 (light | dark | system)
  → store/settings.ts  ─ settings.json 에 저장
  → lib/theme.ts       ─ applyTheme() 가 <html data-theme="light|dark"> 로 새김
  → index.css          ─ :root[data-theme="dark"] 가 의미 토큰 값을 통째로 교체
```

**다크를 고칠 때는 라이트도 같이 고친다.** `:root[data-theme="dark"]` 는 의미 토큰을
빠짐없이 다시 정의해야 한다 — 하나라도 빠지면 라이트 값이 그대로 새어 나와 그 자리만
대비가 무너진다.

### 인라인 코드만 따뜻한 색을 쓴다

크로마틱 액센트는 청록 하나라는 규율의 **유일한 예외**가 `code` 토큰이다. 링크·버튼·활성
표시가 이미 전부 청록이라 코드 칩까지 같은 계열로 두면 구분은 안 되면서 채도만 쌓여
눈이 아프다 → 보색인 테라코타로 뗀다. 예외는 여기서 끝이다. 다른 자리에 두 번째 색이
필요해 보이면 색이 아니라 라벨·아이콘·자리·테두리 굵기로 가른다.

경고(`warning`)도 따뜻한 색이라 헷갈릴 수 있어 `code` 는 색상을 붉은 쪽으로 더 밀었다.
둘은 문맥으로도 갈린다 — 경고는 아이콘과 문장을 데리고 배너로 뜨고, 코드는 모노스페이스
칩으로 문장 안에 박힌다.

**밝은 바탕과 어두운 바탕은 채움 방향이 뒤집힌다.** 라이트에서는 짙은 teal 에 흰 글자,
다크에서는 밝은 teal 에 어두운 글자다(`on-primary` 가 테마마다 다른 게 그래서다).
다크에서 `#0f766e` 에 흰 글자를 얹으면 대비가 3:1 도 안 나온다.

### 투명도 수식(`bg-error/10`)을 쓰지 않는 이유

Tailwind 는 그걸 `color-mix()` 로 뽑으면서 **라이트 값이 박힌 정적 폴백**을 함께 깐다.
그 폴백을 쓰는 웹뷰에서는 다크 테마에서만 색이 어긋난다 → 옅은 면은 언제나
`--color-*-subtle` 토큰으로 만든다.

### 그림자를 `@theme` 에 두지 않는 이유

같은 함정의 다른 얼굴이다. `@theme` 에 `--shadow-*` 를 넣으면 Tailwind 가 `shadow-*`
유틸리티를 만들면서 **값을 그대로 인라인**한다 — 다크에서 변수를 덮어써도 유틸리티는 옛
값을 들고 있어 층이 안 보인다. 그래서 그림자는 평범한 `:root` 변수로 두고 `@utility` 로
직접 선언해 `var()` 를 런타임에 읽게 한다 (`elevate` / `elevate-lg`).

## 활자

Pretendard(본문·제목) + JetBrains Mono(코드).

- **Pretendard** 는 한글과 라틴을 한 패밀리가 갖고 있어 섞인 줄에서 골격이 기울지 않는다.
  가변 폰트 한 벌(2MB)로 45~920 웨이트를 다 쓰므로 `font-weight` 를 자유롭게 써도 된다.
- **JetBrains Mono** 는 라틴 자족만 싣는다. 코드 안의 한글은 `--font-mono` 스택의 다음
  자리인 Pretendard 가 받는다.

| 토큰 | 크기 / 웨이트 | 쓰임 |
|---|---|---|
| `text-display-md` | 28 / 600 | 빈 화면 안내 |
| `text-card-title` | 18 / 600 | 모달 제목 |
| `text-subhead` | 16 / 600 | 섹션 제목 |
| `text-body-sm` | 13 / 400 | 기본 본문 |
| `text-body-emphasis` | 13 / 600 | 선택된 탭·라벨 |
| `text-caption` | 12 / 400 | 메타·노드 카드·도움말 |

- **큰 글자는 자간을 좁히고(-0.02em) 본문은 행간을 넉넉히(1.6+) 준다.**
  이 둘이 "딱딱하지 않은" 인상의 대부분을 만든다.
- 웨이트는 **400 / 500 / 600 만** 쓴다. 700 이상은 화면을 다시 굳게 만든다.
- **12px 이 바닥이다.** 노드 카드가 좁아 보이면 글자를 줄이지 말고 카드를 키운다
  (`TURN_WIDTH` / `TURN_HEIGHT` 등이 그래서 그 크기다). 촘촘한 카드 안에서는
  `leading-snug` 으로 행간만 조인다.

## 부품

`src/components/Panel.tsx` 가 공통 부품을 모두 갖고 있다. 새 UI 는 여기서 가져다 쓴다.

- `Button` — `primary`(청록 채움, 화면당 하나) · `secondary`(잉크 채움) ·
  `tertiary`(옅은 면 + 테두리, **기본값**) · `ghost`(배경 없음) · `danger`.
  크기는 `sm` 32px(툴바) · `md` 40px(폼).
- `FIELD` / `FIELD_SM` / `SELECT` / `SELECT_SM` — 입력 크롬. 사방 1px 테두리 + 둥근 모서리.
- `Panel` — 둥근 타일(`rounded-md` + `elevate`). `Modal`, `Tag` 도 같은 파일.

포커스는 전역 `:focus-visible` 이 받는다(2px 링, 바깥으로 2px). 컴포넌트에서 끄지 말 것.

## 색 없이도 읽히게

색맹·흑백 출력에서도 뜻이 남도록, 상태는 항상 **글자나 형태가 먼저** 지고 색은 거든다.

- 도구 결과 — `실행 중 / 완료 / 실패` 글자 + 색
- 셸 결과 — `✓ / ✗` 기호 + 왼쪽 2px 룰
- 키 유무 — 채운 원 `●` / 빈 원 `○`
- 서브에이전트 노드 — 점선 테두리 + 🤝
- 말풍선 — 자리(좌/우) + 꼬리 쪽 모서리를 깎아 말하는 쪽을 가리킨다
- 선택 / 활성 부모 — 청록 2px / 잉크 2px (색이 아니라 명도로도 갈린다)
- `Tag` 의 글자는 언제나 잉크색이다. 옅은 면 위에 같은 계열의 색 글자를 얹으면
  라이트/다크 어느 한쪽에서 반드시 대비가 무너진다.

## 손댈 때 확인할 것

```bash
pnpm typecheck && pnpm test && pnpm build
```

`bg-hairlne` 같은 오타는 Tailwind 가 **조용히 아무것도 만들지 않아서** 타입체크도 테스트도
못 잡는다. 색이 안 먹으면 빌드된 CSS 에 그 클래스가 있는지 먼저 본다:

```bash
grep -o 'bg-hairline[^{]*{[^}]*}' dist/assets/index-*.css
```

같은 이유로 `!bg-...` 같은 v3 문법도 죽는다 — Tailwind v4 에서 important 는 **접미사**(`bg-x!`)다.

## 아직 안 쓰는 토큰

`inverse-canvas` · `inverse-surface` · `inverse-ink` · `inverse-ink-muted` 는 반전 표면용으로
정의만 남겨 둔 자리다. `focus` 는 유틸리티가 아니라 `index.css` 의 `:focus-visible` 규칙이 쓴다.
